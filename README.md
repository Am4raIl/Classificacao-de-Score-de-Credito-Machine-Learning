# Classificao-de-Score-de-Credito-Machine-Learning
Projeto prático da disciplina de Aprendizado de Máquina focado na classificação de score de crédito de clientes. O repositório contém um pipeline completo, desde a análise exploratória e limpeza de dados até a modelagem e avaliação com algoritmos como Random Forest e KNN, utilizando Python e bibliotecas como Scikit-Learn e Pandas.
